
- 교육시간
- [ ] 월요일 13:00~18:00
- [ ] 화~금 10:00~18:00
- [ ] 해당 요일의 시작 시각으로부터 5분초과는 지각이다.
- [ ] 해당 요일의 시작 시각으로부터 30분초과는 결석이다.
- [ ] 등교하지 않으면 결석이다.
- [ ] 캠퍼스 운영시간은 매일 08:00~23:00이다.
- [ ] 주말 및 공휴일은 출석을 받지 않는다.

- 누적 지각 및 결석 횟수에 따라 경고 또는 면담을 시행한다.
- [ ] 지각 3회는 결석 1회로 간주한다.
- [ ] 경고 대상자 : 결석 2회 이상
- [ ] 면담 대상자: 결석 3회 이상
- [ ] 제적 대상자: 결석 5회 초과 → 제적 시행

기능 선택
- [ ] 오늘 날짜 출력
- [ ] [ERROR] 잘못된 형식을 입력하였습니다 - (기능에서 1,2,3,4,Q 외에 입력한경우)

출석 확인
- [ ] 닉네임과 등교시간을 입력하면 출석할 수 있다.
- [ ] [ERROR] 등록되지 않은 닉네임입니다.
- [ ] [ERROR] 잘못된 형식을 입력하였습니다 - (시간 형식이 올바르지 않습니다.)
- [ ] [ERROR] 12월 14일 토요일은 등교일이 아닙니다. - (주말 또는 공휴일에 출석을 확인하는 경우)
- [ ] [ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다. - (등교시간이 캠퍼스 운영시간이 아닌 경우)
- [ ] 출석 후 출석기록을 확인할 수 있다.
- 이미 출석한 경우, 다시 출석할 수 없다. 
- [ ] [ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해주세요.

출석 수정
- [ ] 닉네임, 수정하려는 날짜, 등교시간을 입력해 기록을 수정한다.
- [ ] [ERROR] 등록되지 않은 닉네임입니다.
- [ ] [ERROR] 날짜는 1~31 사이 숫자여야합니다.
- [ ] [ERROR] 12월 14일 토요일은 등교일이 아닙니다. - (주말 또는 공휴일에 출석을 수정하는 경우)
- [ ] [ERROR] 아직 수정할 수 없습니다. - (미래 날짜로 출석을 수정할 수 없습니다.)
- [ ] [ERROR] 잘못된 형식을 입력하였습니다 - (시간 형식이 올바르지 않습니다.)
- [ ] 수정 후에는 변경 전과 변경 후의 출석 기록을 확인할 수 있다.


크루별 출석 기록 확인
- [ ] 닉네임을 입력하면 전날까지의 크루 출석기록을 확인할 수 있다.
- [ ] [ERROR] 등록되지 않은 닉네임입니다.
- [ ] 각 날마다 출석, 지각, 결석 여부가 같이 출력되야한다.
- [ ] 출석, 지각, 결석 횟수가 출력되야한다.
- [ ] 경고 면담 제적 대상자인지 출력해야한다.



제적위험자 확인
- [ ] 전날까지의 크루 출석 기록을 바탕으로 제적 위험자를 파악한다.
- [ ] 제적, 면담, 경고 대상자 순으로 정렬하여 출력한다.
- [ ] 대상 항목별 정렬 순서는 지각을 결석으로 간주해 내림차순한다.
- [ ] 출석 상태가 같으면 닉네임으로 오름차순한다.


- [ ] 프로그램이 시작하면 크루와 12월 출석 기록은 attendances.csv를 조회한다.
- [ ] 파일 내용은 수정할 수 없다.

- [ ] 시간은 24시간 형식만 사용한다 ex. 22:30
- [ ] 프로그램은 사용자가 종료할 때까지 종료되지 않는다.
- [ ] 해당 기능을 수행하고 초기화면으로 돌아간다.
- [ ] 잘못된 값을 입력할 경우 "[ERROR]" 메세지와 함꼐 IllagaArgumentException을 발생시킨 후 애플리케이션은 종료되어야한다.
