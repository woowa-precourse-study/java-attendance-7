

### 기능
- [x] 출석 파일 읽어와 VO로 만들기
- [ ] 지각 규칙 기능 추가
- [ ] 경고 및 면담 기능 추가
- [ ] 출석 확인 기능 추가
- [ ] 크루별 출석 기능 확인
- [ ] 재적 위험자 확인 기능 추가



### 지각 규칙
- [ ] 월요일 13:00~18:00
- [ ] 화~금 10:00~18:00
- [ ] 5분 초과는 지각이다.
- [ ] 30분 초과는 결석이다.
- [ ] 출석기록이 없으면 결석이다.
- [ ] 주말과 공휴일은 출석 여부를 체크하지 않는다.


### 경고 및 면담
- [ ] 지각 3회는 결석 1회로 간주한다.
- [ ] 결석횟수가 2회 이상이면 경고 대상자이다.
- [ ] 결석횟수가 3회 이상이면 면답 대상자이다.
- [ ] 결석횟수가 5회 초과하면 제적이다.

### 출석 확인 기능
- [ ] 닉네임과 출석 시간을 입력한다.
- [ ] 출석 후 출석 기록을 출력한다.
- [ ] 이미 출석한 경우, 다시 출석할 수 없다.
- [ ] 캠퍼스 운영 시간에만 출석이 가능하다. (평일 08:00~23:00)
- [ ] 공휴일 (주말, 크리스마스)는 출석이 불가능하다.

### 출석 확인 석능
- [ ] 닉네임, 수정하려는 날짜, 등교 시간을 입력한다.
- [ ] 변경 후에는 변경 전과 변경 후를 출력한다.

### 크루별 출석 기능 확인
- [ ] 닉네임을 입력한다.
- [ ] 해당 크루의 전날까지의 출석기록을 출력한다.
- [ ] 출석, 지각, 결석 횟수를 카운트한다.
- [ ] 출석, 지각, 결석 횟수를 출력한다.
- [ ] 지각, 결석에 따른 경고 및 면담 여부를 출력한다.

### 재적 위험자 확인
- [ ] 전날까지의 기록으로 제적 위험자를 출력한다.
- [ ] 지각 3회를 결석 1회로 치환해 최종 결석과 지각 횟수를 구한다.
- [ ] 같은 항목 내에서 결석과 지각횟수를 내림차순으로 정렬한다.
- [ ] 제적 → 면담 → 경고 순 정렬한다.
- [ ] 출석 상태가 같으면 닉네임을 오름차순 정렬한다.



### 에러 메세지
- [ ] [ERROR] 잘못된 형식을 입력하였습니다.
- [ ] [ERROR] 등록되지 않은 닉네임입니다.
- [ ] [ERROR] 12월 14일 토요일은 등교일이 아닙니다.
- [ ] [ERROR] 아직 수정할 수 없습니다.
- [ ] [ERROR] 캠퍼스 운영 시간에만 출석이 가능합니다.
- [ ] [ERROR] 이미 출석을 확인하였습니다. 필요한 경우 수정 기능을 이용해주세요.
